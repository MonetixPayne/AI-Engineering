# ai-engineering-proof

Working log for a 24-week applied-AI engineering path (1 hour a day).
Exercise book: [ai-engineering-hub](https://github.com/patchy631/ai-engineering-hub).

**Rule of this repo: no eval, no ship. No number, no claim.**

Each phase folder ends with a README whose first block is a results table
(quality metric, p50/p95 latency, cost per 1k calls) — not a feature list.

| Phase | Focus | Gate artifact | Status |
|---|---|---|---|
| `00-foundations` | Raw API loop + cost accounting | cost-logged enrichment CLI | ⬜ not started |
| `01-retrieval` | Retrieval quality | recall@k table, 3 configs, own corpus | ⬜ not started |
| `02-evals` | Evals + observability | CI that blocks merges on regression | ⬜ not started |
| `03-agents` | Agents and workflows | failure taxonomy + workflow-vs-agent note | ⬜ not started |
| `04-mcp-memory` | MCP, memory, context | published MCP server | ⬜ not started |
| `05-production` | Serving and guardrails | live endpoint + load test + incident | ⬜ not started |
| `06-model-depth` | Fine-tune / distil | cost+accuracy table vs frontier baseline | ⬜ not started |
